# Harsh.dev Portfolio

A responsive futuristic dark portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in your browser, or use the VS Code Live Server extension.

## Personalize before publishing
1. Add your original portrait at `assets/profile-photo.jpg` (square or portrait crop recommended).
2. Replace `YOUR_EMAIL@gmail.com` in `index.html` with your real email.
3. Replace the LinkedIn placeholder link with your actual profile URL.
4. Update GitHub links if your username changes.
5. Add your actual resume PDF as `assets/Harsh_Thakur_Resume.pdf`.
6. Add individual GitHub repository links to each project card.
7. Review the skill descriptions and only keep skills you can confidently discuss.

## Publish with GitHub Pages
1. Create a public repository, e.g. `harsh-portfolio`.
2. Upload all files and folders from this project.
3. Open repository Settings → Pages.
4. Select Deploy from a branch, branch `main`, folder `/ (root)`, then Save.

Your site will be available at `https://YOUR_USERNAME.github.io/harsh-portfolio/` after deployment.

## Notes
The profile image and resume are intentionally placeholders because your original photo and final resume were not attached. The skill progress bars are illustrative; adjust them to reflect your real ability.
